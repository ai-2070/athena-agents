# Craft app icons

The storytold Craft apps' own icons, shown for MCP servers and connectors named after an app
(`photocraft`, `vectorcraft`…). `web/crafticons.ts` picks them.

Each file is the app's 64 px icon, copied unmodified from
`assets/app-icon/hicolor/64x64/apps/ai.storyteller.<app>.png` in its repository. The designs belong to
the ArtCraft Team and each app's contributors and are licensed like the apps: MIT OR Apache-2.0.
Refresh them from the same path; never redraw them. SolidCraft comes from Tangency Labs rather than storytold:
its icon is `assets/icons/app/linux/exports/hicolor/64x64/apps/io.tangencylabs.solidcraft.png`, licensed Apache-2.0.
