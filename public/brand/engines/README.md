# Engine marks

Vendored from the official project sites and repositories; brand names and marks belong to their owners. No network request is needed at runtime.

- hermes: https://raw.githubusercontent.com/NousResearch/hermes-agent/main/website/static/img/favicon.svg
- pi: https://pi.dev/favicon.svg, split in two: `pi.svg` has its light-mode fill and `pi-dark.svg` its dark-mode fill, so the mark follows the app’s colour scheme rather than the computer’s
- omp: https://raw.githubusercontent.com/can1357/oh-my-pi/main/packages/collab-web/public/favicon.svg
- openclaw: https://raw.githubusercontent.com/openclaw/openclaw/main/ui/public/favicon.svg

OpenClaw’s animation elements are removed for a still settings icon.

- Venice: https://venice.ai/brand/venice-keys-svg.zip (official keys mark). `venice.svg` has the approved Deep Blue fill and `venice-dark.svg` the Off White one, so the mark follows the app’s colour scheme; paths are unchanged.

- handbrakecli.png: https://raw.githubusercontent.com/HandBrake/HandBrake/HEAD/win/CS/HandBrakeWPF/Views/Images/logo64.png

- imagemagick.png: https://raw.githubusercontent.com/ImageMagick/ImageMagick/HEAD/app-image/icon.png

- prusaslicer.svg: https://raw.githubusercontent.com/prusa3d/PrusaSlicer/HEAD/resources/icons/PrusaSlicer.svg

- orcaslicer.png: https://raw.githubusercontent.com/OrcaSlicer/OrcaSlicer/HEAD/resources/images/OrcaSlicer_64.png

- Painter and Designer: https://cdn.experienceleague.adobe.com/assets/Adobe-Enterprise-Docs/substance-3d.en/main/help/substance-3d-general/assets/substance3d-icons.zip (Adobe’s official color application icons).

- VS Code: https://code.visualstudio.com/assets/branding/code-stable.png (the branded ribbon, rather than the open-source Code icon)
- Orca: icon_128x128.png from the installed Orca.app’s official icon.icns.

- FFmpeg: https://raw.githubusercontent.com/FFmpeg/web/HEAD/htdocs/favicon.ico, converted to PNG.
